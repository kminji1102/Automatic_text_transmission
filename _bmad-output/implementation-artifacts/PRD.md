# 인터뷰 SMS 자동 발송 PRD v4.0

> 작성일: 2026-05-22
> 버전: v4.0
> 변경 이유:
> - 기수 매핑을 정확히 일치(==) → 포함 여부(contains)로 변경
> - "노션 자동 조회 + 수동 발송 확인" 구조 명시 강화

## 1. 잠긴 결정 (Locked Decisions)

| 항목 | 결정값 | 비고 |
|---|---|---|
| 언어 | Python 3.10 이상 | |
| 노션 조회 | 자동 (`인터뷰일시` = 오늘 KST) | |
| 발송 실행 | **수동** — 목록 미리보기 후 담당자 Y 입력 필수 | 자동 발송 없음 |
| 자동 스케줄러 | 없음 (1단계) | 2단계로 미룸 |
| 기수 매핑 방식 | **포함(contains)** — 기수 필드값에 "33기"가 들어있으면 33기로 처리 | 정확히 "33기"가 아닌 "SFAC 33기" 등 다양한 형태 대응 |
| 기수 매핑 저장 | `config.py`의 `COHORT_SENDER_MAP` 하드코딩 | 변경 시 수동 수정 |
| 문자 내용 | 고정 문구 (동적 변수 없음) | 전원 동일 문구 |
| 중복 방지 | 같은 날짜 + 같은 연락처 성공 발송 기록 → 자동 건너뜀 | 1단계 필수 |
| 로그 | `logs/YYYY-MM-DD.csv` (UTF-8-BOM) | |
| 외부 패키지 | `requests`, `python-dotenv` 2개만 | |
| API 타임아웃 | 노션·뿌리오 각 30초 | |
| 외부 자동화 툴 | 사용 안 함 | |

## 3. 모듈 카탈로그 (1단계 — 5개)

| ID | 파일명 | 역할 | 입력 | 출력 |
|---|---|---|---|---|
| M-001 | `main.py` | 전체 흐름 실행, Y/N 발송 확인 | 없음 (수동 실행) | 없음 (결과는 CSV) |
| M-002 | `config.py` + `.env` | API 키·기수 매핑·문자 내용 관리 | `.env` 파일 | 설정값 딕셔너리 |
| M-003 | `notion_client.py` | 노션 DB 당일 예정자 조회 + 정규화 + 기수 resolve | 오늘 날짜, DB ID, 토큰 | `List[dict]` |
| M-004 | `ppurio_client.py` | 뿌리오 LMS 1건 발송 | 수신번호, 발신번호, 문자내용 | `dict` (결과) |
| M-005 | `logger.py` | CSV 결과 기록 + 중복 발송 확인 | 결과 리스트, 날짜 | `logs/YYYY-MM-DD.csv` |

### 모듈별 예외 상태

| 모듈 | 예외 조건 | 처리 | exit code |
|---|---|---|---|
| M-001 | 담당자 N 입력 | 즉시 종료, 발송 없음 | 0 |
| M-002 | `.env` 없음 또는 필수 키 누락 | 오류 메시지 출력 후 종료 | 1 |
| M-003 | 노션 API 타임아웃·오류 | 예외 raise → M-001이 CSV 기록 후 종료 | 1 |
| M-003 | 연락처 형식 오류 | 해당 건 `형식오류` 표시, 계속 진행 | 0 |
| M-003 | 중복 연락처 (노션 DB 내부) | 첫 번째만 남기고 중복 제거 | 0 |
| M-003 | 기수 필드에 알려진 기수 키워드 없음 | `resolved_cohort=None`, M-004에서 `매핑없음` 처리 | 0 |
| M-004 | `sender=None` (기수 매핑 실패) | `결과=매핑없음` 반환, 다음 건 진행 | 0 |
| M-004 | 뿌리오 API 타임아웃·오류 | `결과=실패` 반환, 다음 건 진행 | 0 |
| M-005 | 오늘 이미 성공 발송된 번호 | `결과=중복건너뜀`, 발송 제외 | 0 |

## 4. 데이터 스키마

### 4.1 기수 포함 여부 매핑 동작 예시

| 노션 기수 필드값 (예시) | 포함 여부 검사 | resolved_cohort | 발신번호 |
|---|---|---|---|
| `"33기"` | "33기" 포함 ✅ | `"33기"` | `01025327302` |
| `"SFAC 33기"` | "33기" 포함 ✅ | `"33기"` | `01025327302` |
| `"플레이데이터 34기 수강생"` | "34기" 포함 ✅ | `"34기"` | `01067757302` |
| `"35기 지원자"` | 매핑 키 없음 ❌ | `None` | 없음 → `매핑없음` |
| `""` (빈 값) | — | `None` | 없음 → `매핑없음` |

### 4.2 logs/YYYY-MM-DD.csv 형식

| 컬럼 | 설명 | 예시 |
|---|---|---|
| `executed_at` | 발송 시각 (ISO 8601) | `2026-05-22T09:05:03` |
| `name` | 수신자 이름 | `홍길동` |
| `phone` | 정규화된 수신번호 | `01012345678` |
| `cohort` | 노션 기수 필드 원본값 | `SFAC 33기` |
| `resolved_cohort` | 매핑에 사용된 기수 키 | `33기` |
| `sender_number` | 발신번호 | `01025327302` |
| `result` | 결과값 | `성공` / `실패` / `형식오류` / `매핑없음` / `중복건너뜀` |
| `error_msg` | 오류 내용 | `35기 발신번호 없음` |

> `cohort`(노션 원본값)와 `resolved_cohort`(매핑에 사용된 키)를 분리 기록해서 나중에 어떤 값으로 매핑됐는지 확인 가능
