# 설계: CLI 발송 대상 선택 기능

- 날짜: 2026-05-28
- 상태: 사용자 검토 대기
- 관련 모듈: `main.py` (단일 파일 내 변경)
- 관련 AC: FRD M-001

## 배경

현재 `main.py`는 노션에서 오늘 예정자를 조회해 미리보기를 출력한 뒤,
`confirm_send()`로 **Y/N 전체 발송 / 전체 취소**만 처리한다. 담당자가 목록 중
일부에게만 보내거나 특정 인원을 빼고 싶어도 방법이 없어, 전체 발송하거나
노션 원천을 수정한 뒤 재실행하는 수밖에 없다.

## 목표

미리보기 이후 담당자가 **발송할 대상을 번호로 선택**해, 선택된 인원에게만
발송할 수 있게 한다.

### 범위 (In)
- 조회된 오늘 목록에서 번호로 발송 대상 선택 (포함 방식)
- 전체 선택(Enter), 취소(N), 잘못된 입력 재시도
- 선택 후 최종 Y/N 재확인

### 범위 외 (Out) — YAGNI
- 연락처/기수 즉석 수정 (노션 원천에서 처리)
- 노션에 없는 신규 인원 즉석 추가
- 정렬/필터, 다중 데이터소스 선택 등

## 요구사항 / 동작

1. `show_preview()`로 번호가 매겨진 목록을 출력한다(기존 유지).
2. 프롬프트: `발송할 번호를 입력하세요 (예: 1,3 / 전체는 Enter / 취소는 N): `
   - 빈 입력(Enter) → 전체 선택
   - `N`/`n` → 취소, "발송을 취소했습니다" 출력 후 종료(0)
   - 번호 목록(쉼표 또는 공백 구분) → 해당 번호만 선택. 중복 무시, 원래 순서 유지.
   - 범위를 벗어난 번호·숫자가 아닌 입력 → 오류 안내 후 재입력. 발송·종료 없음.
3. 선택된 대상을 다시 출력: `선택된 발송 대상 (N명):` + 목록
4. 최종 확인 프롬프트: `이대로 발송하시겠습니까? (Y/N): `
   - `Y` → 선택된 대상에게만 발송
   - 그 외 → 취소, 종료(0)

## 컴포넌트 (모두 `main.py` 내부)

### `parse_selection_indices(raw: str, count: int) -> list[int]`
순수 함수(입출력 없음). 입력 문자열과 목록 길이를 받아 1-기반 인덱스 리스트 반환.
- 빈 문자열/공백만 → `[1..count]` (전체)
- 쉼표/공백으로 구분된 숫자들 → 정렬·중복제거된 in-range 인덱스
- 범위 초과(`< 1` 또는 `> count`), 숫자 아님 → `ValueError`

### `prompt_recipients(send_candidates: list[dict]) -> list[dict] | None`
얇은 입출력 래퍼.
- 입력 루프: `N`/`n` → `None`(취소) 반환. 그 외엔 `parse_selection_indices` 호출,
  `ValueError`면 오류 출력 후 재입력.
- `EOFError`(비대화형 stdin) → `None`(취소)로 안전 처리.
- 선택된 부분집합 출력 후 최종 Y/N. `Y`면 부분집합 반환, 아니면 `None`.

### `main()` 변경
- 기존 `confirm_send()` 호출부를 `prompt_recipients(send_candidates)`로 교체.
- 반환이 `None` → "발송을 취소했습니다" 로그 후 종료(0).
- 리스트 → 그 부분집합을 기존 발송 루프(`send_lms` 등)에 전달.
- `confirm_send()`는 제거(대체됨).

## 데이터 흐름

```
fetch → precheck(형식오류/중복건너뜀 분리) → show_preview(send_candidates)
      → prompt_recipients → (선택 부분집합) → send_lms 루프
      → write_results → summary
```

중복발송 방지(`is_already_sent_today`)·CSV 기록·요약 로직은 변경 없음.
precheck로 걸러진 형식오류/중복건너뜀 행은 기존대로 CSV에 기록된다.

## 에러 처리

- 잘못된 선택 입력: 재입력 유도(크래시·발송 없음).
- 비대화형/EOF: 취소로 처리해 우발 발송 방지.
- 선택 결과 공집합: 발생 불가(전체/취소/번호 중 하나로 귀결).

  - 빈 입력 → 전체 인덱스
  - `"1,3"` → `[1, 3]`
  - `"2 4"` → `[2, 4]` (공백 구분)
  - `"1,1"` → `[1]` (중복 제거)

  - 비숫자(`"a"`), `"0"` → `ValueError`
- (선택) `prompt_recipients`: `input` monkeypatch로 취소 / 선택+Y / 선택+N 경로 검증.
